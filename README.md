# React Gaming

React Gaming is a modern web application built with **React 17** and **Material UI 5**. The project follows a component-based architecture and leverages Material Design principles to deliver a responsive, scalable, and visually engaging user interface.

Built on the Material Kit 2 React foundation, the application provides a solid starting point for gaming platforms, dashboards, landing pages, and interactive web applications.

---

# Technologies Used

- React 17
- JavaScript (ES6+)
- Material UI 5
- Emotion
- React Router DOM
- Flatpickr
- React Syntax Highlighter

---

# Prerequisites

- Node.js 14, 15, or 16
- npm 6+

---

# Installation

Clone the repository:

```bash
git clone https://github.com/HetalRupareliya91/react_gaming.git
```

Navigate to the project directory:

```bash
cd react_gaming
```

Install dependencies:

```bash
npm install
```

---

# Running the Application

Start the development server:

```bash
npm start
```

Open:

```
http://localhost:3000
```

---

# Build for Production

Generate an optimized production build:

```bash
npm run build
```
